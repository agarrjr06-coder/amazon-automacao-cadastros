# Checklist de homologação

- [ ] Confirmar integridade do template Excel de entrada e saída.
- [ ] Preservar todas as abas, formatos e validações.
- [ ] Conferir quantidade de SKUs solicitados, elegíveis e retidos.
- [ ] Validar cada SKU filho e o agrupamento interno.
- [ ] Não presumir pai Amazon a partir do pai interno.
- [ ] Conferir valores aceitos para tipo de produto, marca, cores e tamanhos.
- [ ] Validar ação de oferta e atributos obrigatórios/condicionais.
- [ ] Manter EAN/GTIN como pendência manual quando ausente.
- [ ] Não preencher a partir de exemplos do template.
- [ ] Auditar origem de cada valor preenchido.
- [ ] Revisar relatórios de erros e exceções.
- [ ] Obter aprovação operacional antes de qualquer envio à Amazon.
